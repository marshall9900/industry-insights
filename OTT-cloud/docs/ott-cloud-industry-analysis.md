- **电源冷板空白**：PSU液冷供应商几乎空白（机会点）

## 三、OTT液冷采购决策链

```
GPU选型（英伟达/国产）→ 超节点设计（各OTT自研）→ 液冷方案制定（冷板/浸没）
    ↓
组件规格确定 → 认证门槛（OCP/ODCC/OTT自定标准）
    ↓
供应商选择：OEM集成（浪潮/超聚变/宁畅）→ 一级供应商（英维克/维谛）→ 零部件（海悟定位）
    ↓
采购执行：OEM统一采购（大额） + OTT直接采购（特定组件）
```

### 各OTT液冷决策权分布

|------|:---:|:---:|:---:|------|
| 阿里巴巴 | 自研 | ⭐⭐⭐⭐⭐ | 高 | 英维克/高澜/双鸿 |
| 字节跳动 | 自研 | ⭐⭐⭐⭐ | 中高（经OEM） | 英维克/维谛 |
| 腾讯 | 跟随 | ⭐⭐⭐ | 中 | 英维克 |
| 百度 | 自研（昆仑芯） | ⭐⭐ | 中（封闭） | 曙光数创 |
